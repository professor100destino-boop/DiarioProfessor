Base permanente 3.0.0
⬇ Instalar base permanente
Ela instala ao lado do Docência Fácil 2 atual. Não desinstale o aplicativo atual. Primeiro vamos recuperar/conferir seus dados na base permanente.
Depois desta migração: atualizações normais serão feitas em Configurações → Atualizações → Atualizar sistema agora. Não será necessário baixar APK nem instalar por cima para alterações do Professor Control ou do SIAP Fácil.
SIAP Fácil: o controle de login, captcha e navegação passa a ser carregado online. Se o SIAP mudar, a correção também entra pelo botão Atualizar sistema agora, sem trocar o APK.
O APK fica apenas como base Android: armazenamento, arquivos, PDF, backup, WebView e integração com o portal.
